# Projects

**Create blank project** writes only local Harness state. Name is required; goal and constraints can be edited later. A workspace and Codex connection are optional follow-up actions.

**Import a registered Codex project** uses visible official Project/working-directory relationship evidence. Multiple candidates require a user selection. No candidate or ambiguity writes no Project HEAD, Task, Section, or Review truth. Topic-wide cross-conversation collection remains planned.

Archived projects cannot create or dispatch tasks. **Restore project** records a state transition; it does not restore, delete, or rewrite Git or Codex conversations.
