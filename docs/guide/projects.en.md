# Projects

**Create blank project** creates the Harness Project, official Codex Project, CTO/Review control plane, and opens CTO. It does not search history or start an organizer turn.

**Keyword organize** searches active and archived Codex threads and message occurrences, then starts one independent review-gated organizer turn. A missing native capability uses a bounded local index and records that boundary.

**Select conversations** reads only the Codex conversations you check, applies the fixed default knowledge-extraction task plus any additional request you enter, and extracts SOPs, rules, project details, tasks, decisions, and evidence. Similar titles, folders, parent/child threads, or Project relationships never expand the selected scope.

All three entrances leave the form immediately for one progress dialog. Only a real Codex turn with a thread, turn, and process is shown as running.

Archived projects cannot create or dispatch tasks. **Restore project** records a state transition; it does not restore, delete, or rewrite Git or Codex conversations.
