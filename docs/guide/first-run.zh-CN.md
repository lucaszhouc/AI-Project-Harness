# Windows 第一次使用

这份教程按“完全没用过”的情况来写。运行 Harness 本身不需要源码、Node.js 或 npm；只有连接和使用 Codex 时，才需要先安装 Codex CLI。

## 1. 校验下载

公开预发布上线后，请打开对应版本的 GitHub Release 页面，从 **Assets** 下载 Windows x64 portable EXE。不要下载自动生成的 Source code 压缩包，那不是可以直接运行的程序。

下载后，在文件所在目录打开 PowerShell，运行：

```powershell
Get-FileHash -Algorithm SHA256 .\AI-Project-Harness-<version>-portable.exe
```

把结果与 Release 页面提供的 SHA-256 对照。只要不一致，就不要运行。当前仓库还没有获准公开发布，所以这里暂时不放下载链接。

## 2. 启动 Harness

双击刚才校验过的 EXE。第一次打开时，项目列表应该是空的，不应出现开发项目或示例数据。

如果 Windows 提示这是未签名程序，请先确认下载页面和 SHA-256 都正确，再决定是否继续。不要为了运行它而关闭 SmartScreen 或杀毒软件。

打不开时，记下程序版本、SHA-256、Windows 版本、完整报错和时间。不要随便换到其他网站下载。

## 3. 新建项目

点击“小助手”→“新建项目”，填写：

- 项目名称：`我的第一个项目`
- 目标：`创建一项可由我检查的任务`
- 约束：留空
- 项目目录：暂时留空

点击“新建项目”。成功后，它会出现在左侧列表里。这一步只保存项目资料，不会连接 Codex，也不会读取代码或历史对话。

如果某个字段有问题，按红色提示修改即可。创建失败时，已经填写的内容应该还在。

## 4. 检查并连接 Codex（可选）

点击小助手里的“再检查一下”。如果显示“还没检查”，只是尚未确认，不代表一定没安装。

没有 Codex 时，按照 [Codex CLI 官方说明](https://developers.openai.com/codex/cli)安装。然后在终端运行 `codex`，选择 **Sign in with ChatGPT** 或其他官方登录方式。完成后回到 Harness，再检查一次。

准备好后点击“连接 Codex”。Harness 会为当前项目准备必要的 Codex 项目和管理对话，这可能使用你的 Codex 额度。连接失败也不会删除刚才的新项目，你可以处理好问题后重试。

## 5. 创建任务，再明确开始

点击“新建任务”，填写：

- 名称：`创建 hello.txt`
- 验收条件，每行一条：
  - `工作目录中存在 hello.txt`
  - `文件内容为 Hello Harness`
  - `未修改其他文件`
- 审核方式：`用户确认后推进`

点击“创建任务”。这时任务只是保存好了，还不会开始执行。

确认内容没问题后，再点“开始任务”。只有这一步会让 Agent 真正开工。Codex 暂时不可用时，任务仍会保留，不用重复新建。

## 6. 审核并验证持久化

打开项目文件夹，亲自查看 `hello.txt`，再回 Harness 核对结果。不满意可以“拒绝结果”或“退回修改”，但这两个按钮不会自动恢复文件。满意后点“接受并推进 HEAD”；它只更新 Harness 里的项目进度，不会自动 Git commit 或 push。

正常退出，再重新打开同一个 EXE。刚才的项目、任务和审核状态应该仍然存在；需要重新确认的外部能力会提示你再检查一次。

如果结果不一致，请先停下来，按[故障排查](troubleshooting.zh-CN.md)记录问题。
