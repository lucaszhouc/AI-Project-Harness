# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Email [lucaszhouc@gmail.com](mailto:lucaszhouc@gmail.com) with the subject `[SECURITY] AI Project Harness`. This is a single-maintainer project with best-effort response and no SLA.

Do not include credentials, private transcripts, tokens, or unredacted personal paths. Include the affected version, artifact SHA-256, exact reproduction, error ID, and the smallest redacted log excerpt.

## Supported versions

Only the latest `main` revision and latest tagged pre-release are supported.

## Scope

Reports should concern AI Project Harness code or packaging. Stop testing if it risks changing credentials, permissions, public data, or unrelated user files. See [the security and privacy model](docs/security-and-privacy.md).
